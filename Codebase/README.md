# Retail-Customer-Analyzer
Python-based Retail Customer Data Analysis Project

## Project Description
Retail Customer Analyzer is a Python-based project used to analyze retail customer purchasing data.

## Features
1. Spending Statistics
2. High-Value Customer Analysis
3. City-Wise Summary
4. Input Validation
5. Interactive Menu

## Technologies Used
- Python
- Pandas
- CSV Dataset

## Project Files
- main.py - Main Python program
- customers.csv - Customer dataset
- README.md - Project documentation

# How to Run
Install Pandas:
pip install pandas

Run the program:
python main.py

Test case output screenshots are available in the testcases folder.
